# 문해력 퀴즈 설치 설명서

사직고등학교 도서관 · 사고도구어 307장으로 만든 수업용 게임

이 폴더의 파일을 깃허브에 올리면, 학생들이 QR을 찍고 각자 휴대폰으로 동시에 접속해 스피드 퀴즈를 풀 수 있어요. 선생님 화면에서는 순위가 실시간으로 바뀌는 모습을 보여 줄 수 있어요.

## 올릴 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 게임 전체 (낱말 307개 포함) |
| `config.js` | 파이어베이스 설정을 붙여 넣는 파일 |
| `database.rules.json` | 파이어베이스 보안 규칙 (4단계에서 복사해 붙여 넣기용) |
| `README.md` | 이 설명서 |

---

## 1단계. 깃허브 저장소 만들기 (3분)

1. https://github.com 에 로그인합니다. 계정이 없으면 Sign up으로 만듭니다.
2. 오른쪽 위 **+** → **New repository** 를 누릅니다.
3. Repository name에 `munhae-quiz` 처럼 영어 이름을 적습니다.
4. **Public** 을 선택하고 **Create repository** 를 누릅니다.

## 2단계. 파일 올리기 (2분)

1. 방금 만든 저장소 화면에서 **uploading an existing file** 링크(또는 **Add file → Upload files**)를 누릅니다.
2. `index.html`, `config.js`, `database.rules.json`, `README.md` 네 파일을 끌어다 놓습니다.
3. 아래쪽 초록색 **Commit changes** 를 누릅니다.

## 3단계. 웹사이트로 공개하기 (2분)

1. 저장소 위쪽 메뉴에서 **Settings** → 왼쪽 **Pages** 를 누릅니다.
2. Branch에서 **main** 과 **/(root)** 를 고르고 **Save** 를 누릅니다.
3. 1~2분 뒤 새로고침하면 위쪽에 주소가 나타납니다.
   예: `https://아이디.github.io/munhae-quiz/`
4. 이 주소로 들어가면 게임이 열립니다. 여기까지만 해도 게임은 되지만, 점수는 각 기기에만 저장돼요. 여러 기기가 함께 겨루려면 4~5단계를 해 주세요.

## 4단계. 파이어베이스 만들기 (5분, 무료)

1. https://console.firebase.google.com 에 구글 계정으로 들어갑니다.
2. **프로젝트 만들기** → 이름(예: `munhae-quiz`) → 계속 → Google 애널리틱스는 **끄고** → **프로젝트 만들기**.
3. 왼쪽 메뉴 **빌드 → Realtime Database** → **데이터베이스 만들기**.
4. 위치는 **싱가포르(asia-southeast1)** → 다음 → **잠금 모드로 시작** → 사용 설정.
5. 데이터베이스 화면 위쪽의 **규칙** 탭을 누릅니다. 안에 있는 글을 모두 지우고, `database.rules.json` 파일 내용을 그대로 붙여 넣은 뒤 **게시** 를 누릅니다.
6. **데이터** 탭 맨 위에 보이는 주소(`https://...firebasedatabase.app` 또는 `https://...firebaseio.com`)를 메모해 둡니다.

## 5단계. 설정값을 config.js에 넣기 (3분)

1. 파이어베이스 왼쪽 위 **톱니바퀴 → 프로젝트 설정** 을 누릅니다.
2. 아래쪽 **내 앱** 에서 **웹 아이콘 `</>`** 을 누르고, 앱 닉네임(아무거나)을 적고 **앱 등록** 을 누릅니다.
3. 화면에 나오는 `firebaseConfig = { apiKey: "...", ... }` 의 값들을 확인합니다.
4. 깃허브 저장소에서 `config.js` 를 누르고 오른쪽 위 **연필(Edit)** 아이콘을 누릅니다.
5. 따옴표 안에 각 값을 붙여 넣습니다. 특히 **apiKey** 와 **databaseURL** 은 꼭 있어야 해요.
   databaseURL이 파이어베이스 화면에 없으면 4단계 6번에서 메모한 주소를 넣으세요.
6. 선생님 화면 비밀번호를 쓰려면 `teacherPin: "1234"` 처럼 적습니다.
7. **Commit changes** 를 누르고 1~2분 기다린 뒤 게임 주소를 새로고침합니다.

완성된 config.js 예시:

```js
window.QUIZ_CONFIG = {
  firebase: {
    apiKey: "AIzaSy....",
    authDomain: "munhae-quiz.firebaseapp.com",
    databaseURL: "https://munhae-quiz-default-rtdb.asia-southeast1.firebasedatabase.app",
    projectId: "munhae-quiz",
    storageBucket: "munhae-quiz.appspot.com",
    messagingSenderId: "1234567890",
    appId: "1:1234567890:web:abcdef"
  },
  teacherPin: "1234"
};
```

> apiKey는 웹사이트에 공개되어도 괜찮은 값이에요. 누가 무엇을 쓸 수 있는지는 4단계의 보안 규칙이 정합니다.

## 수업에서 쓰는 방법

1. 교실 화면에서 게임 주소를 열고 **PRESS START → 선생님 화면** 을 누릅니다.
2. 화면에 **QR 코드와 방 코드** 가 나옵니다. 학생은 휴대폰으로 QR을 찍고, 이름과 캐릭터를 고릅니다.
   (QR이 안 되면 학생이 게임 주소로 들어와 **방 코드** 를 직접 넣어도 돼요.)
3. **다 같이 시작!** 을 누르면 6초 뒤 모든 학생 화면에서 60초 스피드 퀴즈가 동시에 시작돼요.
   학생이 각자 **스피드 퀴즈** 버튼을 눌러 따로 도전해도 같은 순위표에 올라가요.
4. 게임하는 동안 선생님 화면의 순위가 실시간으로 바뀌고, 학생 화면에도 "실시간 2위 / 25명" 처럼 내 순위가 보여요.
5. 여러 번 도전해도 학생마다 **가장 높은 점수** 만 남아요. 1~3위에는 **선물** 표시가 붙어요.
6. 다음 반 수업 때는 **새 방 만들기** 를 누르면 QR과 방 코드가 바뀌고 순위표가 새로 시작돼요.

기기가 3대뿐이라면 학생들이 돌아가며 이름을 바꿔 적고 도전하면 돼요. 같은 기기라도 이름이 다르면 따로 기록돼요.

## 자주 묻는 것

- **선생님 화면에 "파이어베이스 설정 전"이라고 나와요.** config.js에 apiKey와 databaseURL이 제대로 들어갔는지 확인하고, 커밋 후 1~2분 뒤 새로고침하세요.
- **순위가 안 올라가요.** 4단계 5번의 규칙을 게시했는지 확인하세요. 학교 인터넷이 구글 서비스를 막는 경우도 있어요.
- **음악이 안 나와요.** 화면을 한 번 눌러야 소리가 나요. 오른쪽 위 음악·효과음 버튼도 확인하세요.
- **무료로 계속 쓸 수 있나요?** 파이어베이스 무료 요금제(Spark)는 동시 접속 100명까지 무료라서 한 반 수업에는 충분해요.
